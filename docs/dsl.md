# Язык макросов mKey (DSL)

Требования: SPEC §5.1 (FR-DSL-1…5). Решения по уточнениям: [ADR-0019](adr/0019-dsl-grammar-phase2.md),
строгая запись клавиш — [ADR-0025](adr/0025-strict-keys.md).
Реализация: `internal/lib/dsl` (разбор, форматирование, компиляция), `internal/engine` (выполнение).

## Коротко

Клавиши пишутся **полными именами в фигурных скобках — всегда по одной**, служебные символы
обозначают **действия**. Сочетание получается само собой из зажатия: `^{Ctrl}{C}~{Ctrl}` —
зажали Ctrl, не отпуская нажали C, отпустили Ctrl. Пока есть `^{Клавиша}` и нет `~{Клавиша}`,
все следующие действия выполняются с зажатой клавишей.

| Запись | Что делает |
|---|---|
| `{A}` | нажать и отпустить клавишу A |
| `^{Shift}` | зажать Shift и держать |
| `~{Shift}` | отпустить Shift |
| `~{*}` | отпустить всё, что зажал этот макрос |
| `{Space 500}` | держать Space 500 мс, затем отпустить |
| `{A*3}` | нажать A три раза |
| `^{Ctrl}{C}~{Ctrl}` | сочетание Ctrl+C: зажать Ctrl, нажать C, отпустить Ctrl |
| `[250]` | пауза 250 мс |
| `[1.5s]` | пауза 1,5 секунды |
| `[100..300]` | случайная пауза от 100 до 300 мс |
| `{"Привет!\n"}` | набрать текст (здесь — «Привет!» и Enter) |
| `({A}[50]{B})*10` | повторить группу 10 раз |
| `{Move +10 -5}` | сдвинуть курсор мыши на 10 точек вправо и 5 вверх |
| `{Wheel Down 3}` | прокрутить колесо мыши вниз на 3 щелчка |
| `{Click}` | щёлкнуть левой кнопкой мыши |
| `// текст` | комментарий до конца строки |

Пробелы и переводы строк между действиями ни на что не влияют — длинный макрос можно
писать в несколько строк. Регистр в именах клавиш не важен: `{ctrl}`, `{Ctrl}` и `{CTRL}` —
одно и то же.

Пример: `^{Shift}{"Привет, Вера!"}~{Shift}{Enter}` в русской раскладке напечатает
`ПРИВЕТ, ВЕРА!` и нажмёт Enter.

## Грамматика (EBNF)

```ebnf
sequence   = { space | comment | item } ;
item       = action | pause | group ;

action     = [ "^" | "~" ] "{" space* inner space* "}" ;
inner      = text                                   (* {"..."}                    *)
           | "*"                                    (* ~{*} — только с "~"        *)
           | command                                (* {Move +10 -5}              *)
           | keyexpr ;                              (* {A}, {A*3}, {Space 500}    *)

text       = json-string ;                          (* строковый литерал JSON     *)

command    = command-name { space+ arg } ;          (* имя из реестра команд      *)
arg        = [ "+" | "-" ] number [ "%" ] | word ;   (* 50% — процент экрана        *)

keyexpr    = keyref                                 (* в скобках — одна клавиша   *)
             [ space* "*" space* integer ]          (* повтор                     *)
             [ space+ duration ]                    (* удержание                  *)
             [ space* "=" space* signed-number ] ;  (* положение оси ({pad2.LX=0.5}) *)
keyref     = [ word "." ] ( word | digits )         (* A, Mouse0, pad2.South      *)
           | "#" ( integer | "0x" hex ) ;           (* сырой код evdev            *)

pause      = "[" space* duration [ space* ".." space* duration ] space* "]" ;
duration   = number [ "ms" | "s" ] ;                (* без единиц — миллисекунды  *)

group      = "(" sequence ")" [ space* "*" space* integer ] ;

comment    = "//" { any character except newline } ;
word       = letter { letter | digit | "_" } ;      (* буквы любого алфавита      *)
number     = digits [ "." digits ] ;
```

### Ограничения, которые проверяет разбор

- `^` и `~` нельзя ставить перед текстом, командой, повтором, удержанием и значением оси.
- `{*}` допустим только как `~{*}`.
- Повтор (`*N`) и удержание (`{A 500}`) в одной записи нельзя совмещать.
- Повтор: от 1 до 10 000. Длительность паузы или удержания: не больше 1 часа (защита от «вечных» макросов, SEC-4).
- В случайной паузе `[a..b]` должно быть `a ≤ b`.
- Текст вне `{"..."}` — ошибка с подсказкой «чтобы набрать текст, заключите его в `{"..."}`».
  Экранирования вне текста нет: чтобы набрать `{`, пишите `{"{"}`.
- Неизвестная клавиша — ошибка с подсказкой ближайшего имени: `неизвестная клавиша «Mous0» — возможно, вы имели в виду «Mouse0»?`.
- В скобках — одна клавиша: `{Ctrl+C}` — ошибка с подсказкой «пишите `^{Ctrl}{C}~{Ctrl}`».
- Считаются только крайние скобки: `{{}` и `{}}` означали бы клавишу «{» или «}», но таких
  клавиш нет (это Shift и `[` / `]`) — ошибка с подсказкой: напечатать символ — `{"{"}`,
  нажать клавишу — `{LBracket}`.

### Зажатия и отпускания

Проверяются для макроса целиком (команда `mkey send`, блок «Макрос», текст в режиме «Текстом»):

- клавишу нельзя зажать второй раз, пока она зажата: `^{Ctrl}^{Ctrl}` — ошибка
  «клавиша Ctrl уже зажата»; нажать зажатую тоже нельзя: `^{A}{A}`;
- отпустить можно только зажатую: `~{Ctrl}` без `^{Ctrl}` — ошибка «клавиша Ctrl не была зажата»;
- `{Ctrl}` и `{LCtrl}` — одна и та же клавиша (левый Ctrl): `^{Ctrl}{C}~{LCtrl}` — правильно;
- клавиши, которые остались зажатыми в конце макроса, mKey отпускает сам (см. ниже).

Блоки «Зажать клавишу» и «Отпустить клавишу» в событии — отдельные шаги: блок «Отпустить»
отпускает то, что зажал один из прошлых блоков. В Lua `mkey.send(...)` не проверяется: макрос
можно собирать из нескольких вызовов.

Каждая ошибка содержит строку и столбец (считаются в символах, с 1).

## Сочетания, повтор и удержание

- Сочетание — через зажатие: `^{Ctrl}^{Shift}{T}~{Shift}~{Ctrl}` (Ctrl+Shift+T).
- `{A*3}` — три нажатия с паузой между ними (`key_delay_ms`, по умолчанию 10 мс).
- `{Space 500}` / `{Space 1.5s}` — удержание. `^{Ctrl}{C 200}~{Ctrl}` держит C 200 мс при зажатом Ctrl.
- Обычное нажатие `{A}` держит клавишу `key_hold_ms` (по умолчанию 20 мс): совсем короткие
  нажатия некоторые игры не замечают.

## Набор текста `{"..."}`

- Строка записывается как строковый литерал JSON. Экранирования: `\"`, `\\`, `\/`,
  `\n` → Enter, `\r` → Enter (пара `\r\n` — один Enter), `\t` → Tab, `\b` → Backspace,
  `\uXXXX` (в том числе суррогатные пары). `\f` и неизвестные экранирования — ошибка.
- Каждый символ набирается так, как его набрал бы человек в текущей раскладке: mKey находит
  клавишу и при необходимости сам зажимает Shift.
- **Зажатые через `^{...}` клавиши действуют на набор**, как палец на клавише: если символу
  Shift не нужен, а Shift зажат, получится заглавная буква (или символ над цифрой).
- Если символа нет в текущей раскладке, mKey ищет его в других раскладках системы и,
  если окружение позволяет (сейчас — KDE Plasma), временно переключает раскладку и потом
  возвращает прежнюю. Иначе — понятная ошибка. Вставка через буфер обмена — фаза 8.
- Поддерживаемые раскладки: `us` и `ru`. Остальные — фаза 8 (FR-AD-4).

## Команды

Команды — это записи вида `{Имя аргументы}`, где имя — зарегистрированная команда (не клавиша).

| Команда | Сейчас | Позже |
|---|---|---|
| `{Move dx dy}` со знаками (`{Move +10 -5}`) | относительное перемещение курсора | — |
| `{Move x y}` без знаков | ошибка «пока не поддерживается» | точка экрана в пикселях — фаза 8 (нужен размер экрана от окружения) |
| `{Click}`, `{Click Right}`, `{Click Middle}` | щелчок кнопкой мыши | `{Click x y}` — фаза 8 |
| `{Wheel Up 3}`, `{Wheel Down}`, `{Wheel Left}`, `{Wheel Right 2}` | прокрутка (по умолчанию 1 щелчок) | — |
| `{Touch x y}`, `{Touch x y мс}`, `{Swipe x1 y1 x2 y2 [мс]}` | касание (долгое — с мс) и свайп (по умолчанию 300 мс) виртуального сенсорного экрана | — |

### Касания

Касаются **виртуального сенсорного экрана** проекта (`virtual_devices`, шаблон `touchscreen`).
Точка — проценты экрана (`50%` — середина, `0% 0%` — левый верхний угол) или пиксели (`960 540`;
нужен размер экрана: `modules.desktop.screen: "1920x1080"` в config.yaml, после фазы 8 — сам).
Экран один — имя не нужно; несколько — первым словом: `{Touch экран2 50% 50%}`.

```
{Touch 50% 80%}               коснуться
{Touch 50% 80% 800}           долгое нажатие 0,8 с
{Swipe 50% 80% 50% 20%}       провести снизу вверх за 0,3 с
{Swipe 10% 50% 90% 50% 1000}  провести слева направо за 1 с
```

Палец отрывается в конце касания и при любой остановке макроса.

## Устройства

- Без префикса клавиши идут на виртуальную клавиатуру mKey, кнопки мыши — на виртуальную мышь.
- **Кнопки устройств с авто-ID** (FR-DEV-2, ADR-0026). Устройство, у которого есть кнопки без
  стандартного имени, получает имя `UnKey`, `UnKey2`…, а такие кнопки — номера `001`, `002`…
  (их показывают `mkey devices inspect` и «Устройства» → «Подробнее»):
  - `{UnKey001}` — кнопка 001 устройства UnKey (слитно пишется только у первого устройства);
  - `{UnKey2.001}` — кнопка 001 устройства UnKey2; слитная запись `{UnKey2001}` тоже допустима
    (последние три цифры — всегда номер кнопки), форматтер пишет через точку;
  - `{UnKey.A}` — обычная клавиша A, но только этого устройства.

  Регистр не важен. В горячих клавишах, последовательностях, переназначениях (`from`), условии
  `key_state`, `mkey.is_down()` и `mkey wait key` такая кнопка ловится **только со своего
  устройства** (обычная `{A}` — с любого). В макросах (`send`) клавиши `KEY_*` (например,
  «Калькулятор») нажимает виртуальная клавиатура mKey, кнопки мыши — мышь; кнопки джойстика
  (`BTN_TRIGGER`…) нажать пока нельзя — ошибка «mKey пока не умеет нажимать» (отправка через
  копию устройства — T7.3). Неизвестное устройство или номер — ошибка с подсказкой
  `mkey devices inspect`.
- **Переименование** (FR-DEV-3): устройству и его кнопкам без стандартного имени можно дать
  понятные имена — `mkey devices rename UnKey Sega`, `mkey devices rename Sega Start --button 001`
  или «Устройства» → «Подробнее» → «Переименовать». Тогда пишется `{Sega.Start}`, а старые
  `{UnKey001}`, `{UnKey.001}`, `{Sega.001}` продолжают работать. Имя: буквы любого алфавита,
  цифры и `_`, начинается с буквы, регистр не важен; имя устройства не совпадает с именем
  клавиши, не похоже на авто-ID (`UnKey5`) и не занято; имя кнопки уникально в устройстве.
  Переименовать можно и обычное устройство (например, клавиатуру): оно получит авто-ID.
- **Имена кнопок в проекте** (ADR-0027): при сохранении проекта в файл («Проекты» → «Сохранить
  в файл», `mkey project export`) mKey дописывает в раздел `devices` имена кнопок устройств,
  которые встречаются в проекте. У того, кто загрузит проект, такое же устройство получит эти
  имена при подключении (свои имена важнее) — и события с `{Геймпад.Старт}` заработают.
- **Мастер разметки** («Устройства» → «Подробнее» → «Разметить кнопки»): нажимайте кнопки
  устройства по очереди и давайте каждой имя (или пропустите). В журнале «Следить» кнопку с
  авто-именем можно переименовать щелчком.
- **Виртуальные устройства проектов** (ADR-0028): раздел `virtual_devices` проекта, например
  `- { name: pad2, template: xbox360 }`. Пока проект включён, в системе есть геймпад «mKey pad2»,
  и в макросах: `{pad2.South}` — нажать кнопку A, `^{pad2.LT}` — зажать курок,
  `{pad2.LX=-1}` — стик влево до упора (оси: −1…1, курки `{pad2.LT=0.5}` — 0…1). После макроса
  оси возвращаются в покой. Ось нельзя нажать, кнопке нельзя задать положение — ошибки.

## Горячие клавиши и системные сочетания

Там, где нужно описать **сочетание, которое нажимаете вы** (триггер «Когда я нажимаю клавиши…»,
сочетания записи и экстренной остановки), пишется та же запись зажатием, но без отпусканий:
`^{Ctrl}^{Alt}{H}` — «зажаты Ctrl и Alt, нажата H»; одна клавиша — `{F8}`. Сочетание
срабатывает по нажатию последней клавиши.

## Автоматическое отпускание (FR-DSL-5)

Всё, что макрос зажал (`^{...}`) и не отпустил сам, отпускается при его завершении,
остановке (`mkey stop`) и экстренной остановке (`mkey panic`).
