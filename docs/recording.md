# Запись и воспроизведение ввода

Требования: SPEC §5.5 (FR-REC-1…6), этап 6. Модуль `internal/recorder`, формат — `internal/lib/mkrec`.

## Коротко

```bash
mkey rec игра                 # записать (отсчёт 3 с); закончить: Ctrl+Alt+R в любой программе или Ctrl+C здесь
mkey play игра                # повторить один раз (отсчёт 3 с — переключитесь в игру)
mkey play игра --speed 2      # вдвое быстрее (0.1–10)
mkey play игра --repeat 10    # 10 раз подряд (пауза в конце записи тоже повторяется)
mkey play игра --loop         # повторять, пока не остановите (Ctrl+C или Esc+Backspace+Enter)
mkey play игра --no-moves     # без перемещений мыши
mkey rec list                 # список записей
mkey rec stop                 # закончить запись из другого терминала
mkey rec delete игра          # удалить
```

То же — в окне программы (раздел «Записи») и в проектах: действие `play`
(блок «Воспроизвести запись»), например «по F9 повторить запись»:

```yaml
- id: replay
  trigger: { type: hotkey, keys: "{F9}" }
  actions:
    - play: { name: игра, speed: 1, repeat: 1 }
```

## Что записывается

- По умолчанию — все клавиатуры и мыши (`mkey rec --devices keyboard,mouse,gamepad` или
  `modules.recorder.kinds` в config.yaml). Геймпады и тач записываются, но пока не воспроизводятся.
- Записывается то, что **получили программы**: нажатия, отпускания, кнопки и колесо мыши,
  перемещения; переназначенные клавиши — как переназначены.
- **Не записываются** (защита):
  - нажатия, которые «съел» mKey (горячие клавиши проектов с `consume`, например F8 автокликера);
  - сочетание записи (по умолчанию `^{Ctrl}^{Alt}{R}`) и Ctrl+C, которым остановили запись в
    терминале, — вырезаются;
  - экстренная остановка Esc + Backspace + Enter — заканчивает запись и вырезается из неё;
  - отпускания клавиш, нажатых до начала записи; автоповторы клавиш; служебные события;
  - нажатия, которые делает сам mKey (его виртуальные устройства).
- Частые перемещения мыши склеиваются по 8 мс: траектория та же, строк меньше.

Записи лежат в `~/.local/share/mkey/recordings/<имя>.mkrec` (точное место показывают
`mkey rec list`, `mkey paths`, раздел «Записи» и «Настройки» → «Где что лежит»);
`mkey uninstall --keep-config` их сохраняет.

## Мышь: калибровка (FR-REC-5)

Мышь сообщает только сдвиги, а узнать, где курсор, в Wayland программам нельзя. Поэтому
mKey делает одинаково в любом окружении (решение владельца):

- **перед записью** курсор ставится в центр экрана (в файле — строка `pointer center`),
  дальше записываются сдвиги от этой точки;
- **перед воспроизведением** (и перед каждым повтором) курсор снова ставится в центр, и сдвиги
  повторяются от той же точки.

Центр ставится виртуальным устройством «mKey Pointer» с абсолютными координатами (как у
графического планшета) — это работает и в X11, и в любом Wayland. Если включено ускорение
мыши, путь курсора при повторе может немного отличаться: для точности выберите профиль
ускорения «Плоский» в настройках мыши. С `--no-moves` калибровки нет.

## Воспроизведение

- Идёт через виртуальные клавиатуру и мышь mKey в темпе записи (с учётом скорости).
- Проход длится ровно длительность записи: пауза в конце тоже повторяется (ритм при повторах).
- Любая остановка (конец записи, Ctrl+C, `mkey stop`, экстренная остановка) отпускает всё,
  что было нажато воспроизведением.
- Если в записи удалили нажатие, но оставили отпускание, — отпускание пропускается; если
  удалили отпускание — клавиша отпускается в конце прохода.

## Запись → блоки конструктора (FR-REC-6)

Запись можно превратить в обычное событие и дальше править его в конструкторе, повесить на
горячую клавишу и т. п.: кнопка «Сделать событие» в разделе «Записи» или
`mkey rec convert <имя> [--simplify | --no-simplify]` (без флага программа спросит).

Создаётся **новый выключенный** проект «Из записи «имя»» с событием «Повтор записи» (запуск
вручную). Как превращаются действия:

| В записи | Блок |
|---|---|
| нажатие клавиши до 300 мс | `tap` |
| нажатие дольше 300 мс | `hold {key, ms}` |
| клавиша, пока нажата которой нажали и отпустили другую клавишу, двигали мышь или крутили колесо | `key_down` … `key_up` |
| щелчок левой/правой/средней/боковой кнопкой мыши | `mouse_click` |
| колесо | `wheel {direction, count}` |
| движения мыши между действиями | `mouse_move {dx, dy}` |
| время между действиями | `pause` (паузы короче 20 мс переносятся на следующую) |
| калибровка (`pointer center`) | первый блок `pointer_center` |

**Упрощение движений** (алгоритм Рамера — Дугласа — Пекера, допуск 2 точки) оставляет только
точки, без которых путь отклонился бы заметно: блоков намного меньше, щелчки — в тех же местах.
Без упрощения каждое записанное движение — отдельный блок.

Перекрытие при быстром наборе (нажали «а», нажали «б», отпустили «а») остаётся двумя
нажатиями. Кнопки геймпадов, оси и тач пока не превращаются. Если превращать нечего —
ошибка `api.recording_empty`.

## Формат .mkrec — правка вручную

Обычный текст: одна строка — одно действие. Лишние действия можно просто удалить, время —
поправить (строки сами упорядочатся по времени). Строки, начинающиеся с `#`, — комментарии.

```
mkrec 1
created 2026-09-30T12:00:00Z
device 0 keyboard "AT Translated Set 2 keyboard"
device 1 mouse "Logitech USB Optical Mouse"
pointer center                   ← перед записью курсор поставлен в центр экрана
0.000 0 ^{A}                     ← время (с), номер устройства, действия
0.120 0 ~{A}
0.350 1 move +12 -3              ← сдвиг мыши: вправо 12, вверх 3
0.500 1 ^{Mouse0}                ← нажата левая кнопка
0.620 1 ~{Mouse0}
1.200 1 wheel -1 wheel-hr -120   ← колесо вниз (обычное и высокого разрешения)
5.000 end                        ← конец записи
```

Действия: `^{Клавиша}` — нажать, `~{Клавиша}` — отпустить (имена — как в макросах,
docs/dsl.md; `{#30}` — по коду), `move +dx +dy`, `wheel ±n`, `hwheel ±n`, `wheel-hr ±n`,
`hwheel-hr ±n`, `ev тип код значение` — любое другое событие evdev.

### Если в файле ошибка

Файл с ошибкой не пропадает из списка: `mkey rec list` и раздел «Записи» пишут, в какой строке
ошибка и что не так, например «строка 8 («0.100 0 ~{Hh}») — неизвестная клавиша «Hh»». То же
сообщение выдают `mkey play` и «Сделать событие». Записи первой версии mKey (JSON, до
30.09.2026) не читаются — их нужно записать заново.

## Настройки (config.yaml)

```yaml
modules:
  recorder:
    hotkey: "^{Ctrl}^{Alt}{R}" # начать/закончить запись из любой программы; "" — выключить
                              # (удобнее: mkey hotkeys set record … или «Настройки» в окне)
    kinds: [keyboard, mouse]  # что записывать по умолчанию
    coalesce_ms: 4            # склейка перемещений мыши при воспроизведении
    dir: ""                   # каталог записей (по умолчанию ~/.local/share/mkey/recordings)
```
