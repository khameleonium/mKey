# Lua API mKey

Требования: SPEC §5.3 (FR-LUA-1…3). Реализация: модуль `internal/script/lua` (gopher-lua, Lua 5.1).

Скрипт — действие `lua` в событии проекта:

```yaml
actions:
  - lua: |
      for i = 1, 3 do
        mkey.tap("A")
        mkey.sleep(100)
      end
  - lua: { file: "farm.lua" }        # ~/.config/mkey/scripts/farm.lua
```

Каждое выполнение получает собственное состояние Lua. Скрипт прерывается мгновенно при остановке
события, `mkey stop`, `mkey panic` и экстренной остановке — даже внутри цикла без вызовов `mkey.*`.
Клавиши, зажатые скриптом, отпускаются, когда событие закончится.

## Функции

| Функция | Что делает |
|---|---|
| `mkey.send(dsl)` | выполнить макрос: `mkey.send("^{Mouse0}[500]~{Mouse0}")` (docs/dsl.md) |
| `mkey.tap(key)` | нажать и отпустить: `mkey.tap("Enter")`, `mkey.tap("Ctrl+C")` |
| `mkey.down(key)` / `mkey.up(key)` | зажать / отпустить |
| `mkey.hold(key, ms)` | держать клавишу ms миллисекунд |
| `mkey.type(text)` | набрать текст (по текущей раскладке) |
| `mkey.sleep(ms)` | пауза (прерывается остановкой) |
| `mkey.move_rel(dx, dy)` | сдвинуть курсор мыши |
| `mkey.click([button])` | щелчок: `"Left"` (по умолчанию), `"Right"`, `"Middle"`, `"Back"`, `"Forward"` |
| `mkey.is_down(key)` | зажата ли физическая клавиша сейчас: `if mkey.is_down("Mouse0") then … end`; кнопка устройства с авто-ID — только на нём: `mkey.is_down("UnKey001")` |
| `mkey.toggled()` | включён ли переключатель события (для триггера `on: toggle`) |
| `mkey.held()` | держат ли ещё клавишу, запустившую событие |
| `mkey.var.<имя>` | переменные проекта: `mkey.var.count = (mkey.var.count or 0) + 1` |
| `mkey.event` | таблица `{project, id, name}` выполняемого события |
| `mkey.notify(text[, title])` | уведомление рабочего стола |
| `mkey.run(event[, project])` | запустить другое событие и дождаться его |
| `mkey.log(...)` | записать в журнал mKey (`mkey logs`) |
| `mkey.on_stop(fn)` | вызвать `fn`, если скрипт остановят (для уборки) |

Ошибка в любой функции `mkey.*` (например, опечатка в имени клавиши) останавливает скрипт;
текст ошибки виден в журнале (`mkey logs`).

## Пока не поддерживается (фаза 8)

| Функция | Сейчас |
|---|---|
| `mkey.window()` | возвращает `nil` |
| `mkey.cursor()` | возвращает `nil` |
| `mkey.pixel(x, y)` | возвращает `nil, "pixel is not supported yet"` |
| `mkey.move(x, y)` | абсолютные координаты — `nil` и сообщение |

## Стандартные библиотеки

Доступны все стандартные библиотеки Lua 5.1, включая `os` и `io`: это ваши собственные скрипты.
Чужие проекты со скриптами при импорте выключены — сначала посмотрите, что они делают.

## Lua-плагины

Те же функции доступны в Lua-плагинах (docs/plugins.md, «Lua-плагины»), но с проверкой
разрешений из `plugin.yaml` и без библиотек `os` и `io`. Плагин регистрирует свои виды функциями
`mkey.register_action{...}` и `mkey.register_condition{...}` при загрузке.
