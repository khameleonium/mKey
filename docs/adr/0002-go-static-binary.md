# ADR-0002: Go, один статический бинарник без cgo

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC.md §3 (D2)

## Контекст

Установка должна быть «скачал и запустил», без зависимостей от версий системных библиотек.

## Решение

Backend пишется на Go, ядро собирается с `CGO_ENABLED=0`. cgo допускается только в опциональных модулях за build-тегом и только через отдельный ADR.

## Последствия

Нельзя напрямую использовать libudev, libxkbcommon, PipeWire — нужны pure-Go реализации или внешние процессы.

## Альтернативы

Rust (сложнее для сторонних авторов модулей), Python (зависимости рантайма).
