# ADR-0033: «Сухой прогон» события в редакторе

- **Статус:** принято (2026-10-02)
- **Связано:** T12.3, T5.7, FR-UI-6

## Контекст

FR-UI-6 требует кнопку «Сухой прогон», которая показывает таймлайн действий события без
реального ввода. В API был только `send dry_run` — компиляция одного макроса. Действия события
бывают любыми: макросы, повторы, условия, переменные, уведомления, скрипты, плагины, повтор
записи. Выполнять их «понарошку» нельзя: скрипт, плагин, уведомление или смена переменной — это
настоящие побочные действия.

## Решение

1. **Описание, а не выполнение.** Таймлайн строит движок (`contracts.DryRunner`). Вид действия
   описывает себя через необязательный интерфейс `contracts.ActionDryRunner`
   (`DryRun(ctx, DryRunContext, action)`): добавляет шаги макроса (`Send`), группы (`Group` —
   тело один раз, время повтора умножается; число повторов неизвестно — пометка `open`), заметки
   (`Note`) и время (`Spend`). Встроенные действия движка и «Повтор записи» его реализуют; вид
   без него (скрипты, плагины) показывается строкой «выполнится только при настоящем запуске».
2. **Время** считается по правилам раннера: обычное нажатие — `key_hold_ms` + `key_delay_ms`,
   символ текста — так же, случайная пауза — по наименьшей; переключение раскладки не
   учитывается. У «Если» обе ветки начинаются в одно время, дальше время идёт от более долгой.
   Таймлайн длиннее 1000 строк обрезается.
3. **API:** `POST /api/v1/projects/{id}/events/{event}/dry_run` с телом `{project}` — проект в том
   виде, в каком он в окне (можно несохранённый); проект проверяется так же, как при сохранении.
   Ответ — `contracts.DryRun` (строки `DryStep` с i18n-ключами окна для групп и заметок).
4. **Окно:** кнопка «Прогон» у события → окно с таймлайном (время начала, отступ по
   вложенности, итог); условия показываются названием и кратким содержанием параметров.

## Последствия

- Прогон безопасен: ничего не нажимается, скрипты и плагины не запускаются, переменные не меняются.
- Время примерное; повтор «пока…» показан одним проходом.
- Плагины пока не могут описать свои действия для прогона (протокол ADR-0029 не меняется):
  их действия видны строкой с названием.
