# ADR-0025: Строгая запись клавиш — одна клавиша в скобках, сочетания через зажатие

- **Статус:** принято (решение владельца, 2026-09-30)
- **Связано:** FR-DSL-1, FR-HK-1, FR-REC-2, ADR-0019 (заменяет в части сочетаний `{Ctrl+C}`)

## Контекст

В ADR-0019 допускалась короткая запись сочетаний `{Ctrl+C}` (и в горячих клавишах `{Ctrl+Alt+H}`).
Владелец указал, что это противоречит исходной задумке: в фигурных скобках всегда код одной
кнопки (клавиатура, мышь, геймпад, неизвестные устройства вида `{UnKey001}`), а сочетания
и так понятны из зажатия `^` и отпускания `~`. Смешанная запись вроде `{10109+L10+rCtrl}`
была бы нечитаемой.

## Решение

1. **В скобках — одна клавиша, везде:** в макросах, горячих клавишах, системных сочетаниях.
   `{Ctrl+C}` — ошибка `dsl.chord_in_braces` с подсказками: для макроса `^{Ctrl}{C}~{Ctrl}`,
   для горячей клавиши `^{Ctrl}{C}`.
2. **Горячие клавиши и системные сочетания** записываются зажатием без отпусканий:
   `^{Ctrl}^{Alt}{H}` — зажаты Ctrl и Alt, срабатывает по нажатию H; одна клавиша — `{F8}`
   (`dsl.ParseHotkey`). Касается триггера `hotkey`, сочетания записи
   (`modules.recorder.hotkey`) и экстренной остановки (`modules.input.emergency_stop` —
   теперь строка, а не список).
3. **Зажатия проверяются** для макроса целиком (`mkey send`, блок «Макрос», режим «Текстом»,
   `dsl.CheckHolds`): второе `^` той же клавиши и нажатие зажатой — `dsl.already_held`,
   `~` без `^` — `dsl.not_held`. `{Ctrl}` и `{LCtrl}` — одна клавиша. Оставшиеся зажатыми
   клавиши mKey отпускает сам (FR-DSL-5). Блоки «Зажать»/«Отпустить» в событии и Lua
   `mkey.send` проверяются по отдельности не на отпускание (они продолжают друг друга).
4. **Скобки внутри скобок:** считаются только крайние; `{{}` и `{}}` — ошибка `dsl.brace_key`
   с подсказкой (символ набирается текстом `{"{"}`, клавиша — `{LBracket}`).
5. Поля одной клавиши (блок «Нажать клавишу», переназначения) принимают имя и без скобок
   (`Esc`), как и раньше.

## Последствия

- Проекты с `{Ctrl+Alt+H}` нужно поправить: ошибка сразу подсказывает правильную запись.
- «Нажмите клавишу…» для горячих клавиш выдаёт `^{Ctrl}^{Alt}{H}`.
- Системные сочетания задаются пользователем: `mkey hotkeys`, «Настройки» → «Сочетания mKey»
  (`GET/PUT /api/v1/settings/hotkeys`, сохраняются в config.yaml с комментариями).

## Альтернативы

- Оставить `{Ctrl+C}` как сокращение — отклонено владельцем.
- Горячие клавиши в привычном виде `Ctrl+Alt+H` — отклонено владельцем: запись должна быть
  одинаковой везде.
