# ADR-0003: Демон от пользователя, привилегии — разово через белый список

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC.md §3 (D3)

## Контекст

Root нужен только для установки udev-правил и загрузки модуля `uinput`.

## Решение

Демон работает от пользователя. Привилегированные операции — `mkey privileged <подкоманда>` из фиксированного белого списка без аргументов-путей; содержимое системных файлов зашито в бинарник. Запуск — через бэкенд повышения прав (ADR-0014).

## Последствия

Минимальная поверхность атаки; нет постоянно работающего root-процесса.

## Альтернативы

Системный root-демон (как у ydotool/keyd) — больше рисков, сложнее удаление.
