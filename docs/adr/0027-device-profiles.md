# ADR-0027: Профили устройств — формат и применение

- **Статус:** принято (2026-10-01)
- **Связано:** T7.4, FR-DEV-5, FR-DEV-7, FR-PLG-8, ADR-0026

## Контекст

Имена кнопок необычных устройств (ADR-0026) человек даёт сам. Чтобы не размечать одну и ту же
модель заново и делиться разметкой, нужен **профиль устройства**: файл с именами кнопок для
модели. В mKey он встроен для известных моделей, а человек может положить свой.

## Решение

1. **Формат** — YAML (`lib/devmap.Profile`, версия 1):
   ```yaml
   version: 1
   title: "Sega USB Joystick"
   match: { vid: "0079", pid: "0011" }   # name — точное название устройства (необязательно)
   device_name: Sega                     # необязательно
   buttons: { BTN_TRIGGER: A, BTN_THUMB: B }
   axes: { ABS_THROTTLE: Gas }
   ```
   Кнопки и оси — **кодами ядра**, а не номерами `001`: номер зависит от того, у каких кнопок
   модели нет стандартного имени, а код — нет. Имена — по правилам переименования (ADR-0026);
   неизвестный код, неверное имя или повтор — ошибка разбора.
2. **Источники:** встроенные — `profiles/devices/*.yaml` (пакет `profiles`, встроены в бинарник,
   регистрируются в точке расширения `device_profile` как `contracts.DeviceProfile`; туда же могут
   добавлять профили плагины); профили человека — папка `~/.config/mkey/profiles` (место
   «Профили устройств»), они **важнее** зарегистрированных. Испорченный файл человека
   пропускается с предупреждением в журнале.
3. **Применение:** при узнавании или появлении устройства (запуск, подключение) подходящий профиль
   подставляет имена туда, где их нет; имена человека не меняются, занятые или недопустимые имена
   пропускаются. Устройство с подходящим профилем получает авто-ID, даже если по режиму авто-ID
   не получило бы. Применённый профиль записывается в devices.yaml (`profile`) и **повторно не
   применяется** — убранное человеком имя не возвращается; новый профиль (другой файл)
   применится один раз.
4. **Экспорт** (FR-DEV-5): `mkey devices profile <устройство>`, `GET /api/v1/devices/profile`,
   «Подробнее» → «Сохранить профиль» — профиль из имён устройства (модель — из примет).
5. **Встроенные профили** добавляются только для моделей, разметка которых известна точно. Первый —
   DragonRise Generic USB Joystick (`0079:0006`): кнопки 1…12 по стандарту HID приходят кодами
   `BTN_TRIGGER`…`BTN_BASE6`, имена `B1`…`B12` совпадают с цифрами на корпусе (на живом
   устройстве не проверено).

## Последствия

- Новый профиль применяется при следующем подключении устройства или перезапуске mKey.
- Мастер разметки (часть Б T7.4) пользуется теми же именами и экспортом.

## Альтернативы

- Номера кнопок в профиле — короче, но ломаются, если у модели другой набор кнопок без имени.
- Применять профиль при каждом узнавании — убранные человеком имена возвращались бы.
