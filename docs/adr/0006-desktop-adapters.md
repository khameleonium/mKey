# ADR-0006: Окружение-зависимые функции — через адаптеры с capabilities

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC.md §3 (D6)

## Контекст

На Wayland нет единого API для активного окна, пикселя, позиции курсора, раскладки.

## Решение

Каждая такая функция — контракт; реализации — адаптеры по окружениям (x11, gnome, kde, sway, hyprland, wlroots, portal). Каждый сообщает capabilities; недоступное честно показывается пользователю (`contracts.ErrUnsupported`).

## Последствия

Больше кода, но предсказуемое поведение и возможность добавлять окружения плагинами.

## Альтернативы

Поддержать только X11 и один-два композитора.
