# ADR-0004: Доступ к устройствам через udev-тег uaccess

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC.md §3 (D4)

## Контекст

Демону нужен доступ к `/dev/uinput` и `/dev/input/event*`.

## Решение

Основной способ — udev-правило `70-mkey.rules` с `TAG+="uaccess"` (ACL для пользователя активной сессии). Запасной — группа `input` (нужен перелогин) или `mdev.conf` (ADR-0014).

## Последствия

Не нужен перелогин, доступ есть только у активной локальной сессии. Любая программа пользователя сможет читать ввод — пользователь предупреждается в мастере.

## Альтернативы

Только группа `input` (требует перелогина и действует для всех сессий).
