# ADR-0009: Один API — два транспорта

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC.md §3 (D9)

## Контекст

С демоном работают браузер и CLI.

## Решение

HTTP+WebSocket на `127.0.0.1` для браузера и тот же HTTP поверх Unix-сокета для CLI.

## Последствия

Один набор эндпоинтов и тестов; CLI не дублирует логику.

## Альтернативы

Отдельный RPC для CLI.
