# ADR-0031: Касания в макросах — проценты и пиксели экрана

- **Статус:** принято (решение владельца о единицах — 2026-10-02)
- **Связано:** T12.1, §5.1, FR-VD-1, ADR-0028

## Контекст

Виртуальный сенсорный экран (шаблон `touchscreen`, ADR-0028) создавался, но касаться его из
макросов было нельзя: команды `{Touch x y}` и `{Swipe …}` отвечали «пока не поддерживается».
Точку на экране нужно как-то задавать, а размер экрана в пикселях mKey пока сам не знает
(его дают адаптеры окружений — фаза 8).

## Решение

1. **Единицы (решение владельца — «и то, и другое»):** число со знаком `%` — процент экрана
   (`{Touch 50% 80%}`) — работает всегда; число без знака — пиксели (`{Touch 960 540}`) — если
   известен размер экрана. Грамматика: аргумент команды — `[+|-] number ["%"] | word`.
2. **Размер экрана** — контракт `contracts.ScreenInfo` (модуль desktop): сейчас из настроек
   `modules.desktop.screen: "1920x1080"`, в фазе 8 — от адаптера окружения. Не задан — понятная
   ошибка `dsl.screen_unknown` с подсказкой про проценты.
3. **Какой экран:** без имени — единственный виртуальный сенсорный экран включённых проектов;
   несколько — имя первым словом (`{Touch экран2 50% 50%}`), иначе `dsl.many_touchscreens`.
4. **Команды:** `{Touch x y [мс]}` — касание (мс — долгое нажатие, по умолчанию как нажатие
   клавиши), `{Swipe x1 y1 x2 y2 [мс]}` — свайп (по умолчанию 300 мс, движение шагами по 10 мс).
   Блоки конструктора `touch` и `swipe` (категория «Тач») сводятся к этим командам.
5. **Устройство** (`contracts.TouchSetter`): одно касание в слоте 0 по протоколу multitouch B;
   отрыв — `ABS_MT_TRACKING_ID = -1`. «Отпустить всё» у сенсорного экрана только отрывает палец:
   прежний сброс осей ставил номер касания 0 — для ядра это новое касание (фантомное нажатие на
   экран при каждом окончании макроса). Исправлено и проверено интеграционным тестом.

## Последствия

- Касания работают без настроек; точность в пикселях — по желанию или с фазой 8.
- Мультитач (несколько пальцев, щипок) — не сделан; при необходимости — новые команды и слоты.
