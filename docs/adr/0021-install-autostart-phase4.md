# ADR-0021: Установка, автозапуск и удаление (этап 4)

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC §5.11 (FR-INST-1…7), T4.1–T4.7

## Решение

1. **Автозапуск по умолчанию — стандартный автозапуск рабочего стола** (`~/.config/autostart/mkey.desktop`),
   а не systemd `--user`, как было в SPEC: на части рабочих столов (Cinnamon, Xfce, MATE)
   `graphical-session.target` не достигается, и служба systemd не запустилась бы; кроме того, это
   одинаково работает на системах без systemd. Порядок выбора: XDG → systemd `--user` (если
   `graphical-session.target` активна; даёт перезапуск при сбое) → строка в конфиге композитора
   (Sway, Hyprland, river, labwc, niri; с согласия, помеченным блоком) → ручная инструкция.
   Пользовательские службы runit/dinit/OpenRC не реализованы: XDG и конфиги композиторов покрывают
   эти системы; при необходимости — новый бэкенд `contracts.Autostart` без изменений остального кода.
2. **Манифест учитывает только файлы пользователя** (программа, значок, иконка, автозапуск, блоки
   в конфигах). Системные правила доступа пишет и удаляет `mkey privileged` по зашитому списку путей;
   при удалении они снимаются, если установлены (`DeviceAccess.Installed`).
3. **Членство в группе `input`** (способы group/mdev) при удалении не отзывается автоматически:
   группа могла быть нужна и до mKey. Пользователь получает команду, как выйти из группы.
4. **Меню приложений не обновляется командой `update-desktop-database`**: она создаёт служебный файл,
   который остался бы следом; KDE и GNOME подхватывают новый ярлык сами.
5. **`mkey` без параметров**: не установлен — мастер установки (в терминале, а при запуске двойным
   щелчком — в новом окне терминала); установлен — `mkey gui` (браузер с веб-интерфейсом).
6. **Проверка при каждом запуске** (модуль setup): через 5 с после старта демона — диагностика; при
   проблемах — уведомление «нужна настройка: mkey doctor --fix».
7. **Проверка в мастере без риска для раскладки:** mKey печатает в терминал только цифры и пробел —
   они одинаковы в любой раскладке.

## Последствия

  ядра заменены заглушками); на машине разработчика нет docker/podman, запуск — в CI или VM.
- Установка пакетами (.deb/.rpm/AUR) и обновление — этап 10.
