# ADR-0010: Lua через gopher-lua

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC.md §3 (D10)

## Контекст

Нужен встраиваемый скриптовый язык без cgo.

## Решение

gopher-lua (Lua 5.1, pure Go), отдельный LState на каждый запуск.

## Последствия

Без cgo, простые биндинги; Lua 5.1 вместо 5.4.

## Альтернативы

LuaJIT/Lua 5.4 через cgo; JavaScript-движки (тяжелее).
