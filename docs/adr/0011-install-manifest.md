# ADR-0011: Манифест установленных файлов

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC.md §3 (D11)

## Контекст

Удаление должно быть «без следов».

## Решение

Любая запись файла в систему при установке идёт через API манифеста; удаление работает строго по манифесту.

## Последствия

Гарантированно полное удаление; код установки обязан использовать манифест.

## Альтернативы

Список файлов «вручную» в деинсталляторе.
