# ADR-0014: Системные различия — через платформенные бэкенды

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC.md §3 (D14)

## Контекст

mKey должен работать и на дистрибутивах без systemd (OpenRC, runit, dinit, s6, sysvinit).

## Решение

Init-система, автозапуск, повышение прав, доступ к устройствам, пакетный менеджер — бэкенды в `internal/platform`. systemd — один из бэкендов, а не допущение.

## Последствия

Полная поддержка систем без systemd; прямые вызовы `systemctl`/`pkexec`/`udevadm` вне бэкендов запрещены.

## Альтернативы

Поддержка только systemd (best effort для остальных) — отклонено владельцем.
