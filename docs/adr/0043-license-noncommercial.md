# ADR-0043: Лицензия PolyForm Noncommercial и коммерческая лицензия автора

- **Статус:** принято (2026-10-08, решение владельца)
- **Связано:** LICENSE, COMMERCIAL.md, ADR-0042 (самостоятельный файл макроса)

## Контекст

Владелец хочет, чтобы mKey оставался бесплатным для обычных людей, а за коммерческое использование
получать отчисления, и чтобы у пользователей была возможность поддержать автора (Boosty). Весь код
написан владельцем (единственный автор коммитов, сторонних вкладов нет), поэтому сменить лицензию
он вправе сам.

## Решение

1. С версии 0.9.4 программа — **PolyForm Noncommercial 1.0.0** (официальный текст без изменений,
   строка `Required Notice` с создателем). Бесплатно — личное и иное некоммерческое использование,
   некоммерческие организации; коммерческое использование — по отдельной лицензии автора
   (разовая, подписка или отчисления; `COMMERCIAL.md`, ru + en).
2. Версии до 0.9.3 включительно остаются под MIT (выпущенное отозвать нельзя).
3. Набор для плагинов `pkg/pluginsdk` и примеры плагинов `examples/plugins` — **MIT** (свои файлы
   LICENSE): писать и продавать плагины можно без лицензии автора.
4. Продажа или платное распространение **собранных файлов макросов** (`mkey build`) — коммерческое
   использование; файл показывает лицензию в `--info`.
5. Лицензия видна: `mkey version` (и `--json`: `license`, `support`), главная окна, описание выпуска,
   пакеты (`license: PolyForm-Noncommercial-1.0.0`), README.
6. «Поддержать автора» — `https://boosty.to/khameleonium`: README (ru, en), окно (боковое меню,
   главная), меню значка в трее, кнопка Sponsor на GitHub (`.github/FUNDING.yml`).

## Последствия

- Лицензия больше не «открытая» по определению OSI: GitHub показывает её как другую, официальные
  репозитории дистрибутивов, скорее всего, пакет не возьмут (AUR — можно, с `license=('custom')`).
- Внешние участники охотнее помогают проектам с открытой лицензией; при приёме чужих изменений
  понадобится их согласие на коммерческое лицензирование (CLA) — иначе эти части автор продавать
  не сможет.
- Тексты для пользователя — не юридическая консультация; условия коммерческой лицензии
  закрепляются договором.

## Альтернативы

- AGPL + коммерческая лицензия — бесплатно и для бизнеса, платят только те, кто не хочет открывать
  изменения; владелец выбрал вариант строже.
- Оставить MIT — заработок только на пожертвованиях и услугах; отвергнуто.
