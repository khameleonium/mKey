# ADR-0007: YAML-модель — единственный источник истины

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC.md §3 (D7)

## Контекст

Проект настраивается и через GUI, и вручную, и через CLI.

## Решение

Проекты и настройки хранятся в YAML; GUI и CLI меняют их только через API демона; изменения на диске подхватываются на лету.

## Последствия

Нет рассинхронизации форматов; файлы удобно версионировать и править руками.

## Альтернативы

Бинарный/БД-формат для GUI и текст для CLI.
