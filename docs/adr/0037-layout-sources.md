# ADR-0037: Источники раскладок и «слепой» набор текста

- **Статус:** принято (2026-10-08, по просьбе владельца)
- **Связано:** FR-AD-4, T8.9, ADR-0019 (раскладки)

## Контекст

В сессии X11 mKey не видел раскладки (источник «config»): текст в макросах печатался только в
раскладке из настроек и не переключал её. Владелец попросил: исправить X11; если раскладку увидеть
нельзя — предупреждать и печатать текст просто нажатиями клавиш (раскладкой занимается сам
пользователь); оставить место для модуля или плагина, который научит mKey видеть раскладку в
неизвестной системе.

## Решение

1. **Точка расширения `layout_source`** (`contracts.PointLayoutSource`), тип —
   `contracts.LayoutSource`: `LayoutProvider` + `Supports(SessionInfo)`. Модуль `desktop`
   регистрирует встроенные источники (KDE, GNOME, X11) и спрашивает по порядку регистрации те, что
   подходят к сессии; первый ответивший без ошибки — источник раскладок. Другой модуль может
   зарегистрировать свой источник в `Init` (модуль `desktop` читает точку при каждом запросе).
2. **X11** — свой маленький клиент протокола X11 без внешних зависимостей
   (`internal/desktop/x11`): раскладки — свойство `_XKB_RULES_NAMES` корневого окна, текущая —
   группа XKB (`XkbGetState`), переключение — `XkbLatchLockState`. Авторизация — MIT-MAGIC-COOKIE-1
   из `XAUTHORITY` / `~/.Xauthority`. Только чтение и смена группы, ввода в сессию нет.
3. **«Слепой» режим** (`LayoutInfo.Blind`): ни один источник не ответил — раскладки берутся из
   настроек, а движок печатает текст нажатиями клавиш как есть, не переключая раскладку (символ
   ищется в таблицах раскладок из настроек, затем во всех известных). Один раз за запуск — запись в
   журнал и уведомление `engine.layout_blind`; `mkey doctor` показывает предупреждение.

## Последствия

- Контракт `LayoutInfo` получил необязательное поле `blind` (API `/api/v1/layouts` — тоже).
- Ошибка каждого источника пишется в журнал один раз, а не на каждый набор текста.
- Плагины (внешние процессы) пока не могут быть источником раскладок: протокол плагинов этого не
  умеет; место в архитектуре — точка `layout_source`.

## Альтернативы

- Библиотека X11 (`xgb`) — внешняя зависимость ради трёх запросов; отвергнуто.
- `setxkbmap -query` / `xkb-switch` — внешние программы, которых может не быть; отвергнуто.
- Ошибка вместо «слепого» набора — владелец попросил печатать нажатиями и предупреждать.
