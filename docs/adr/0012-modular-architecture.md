# ADR-0012: Модульная архитектура

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC.md §3 (D12)

## Контекст

Функции должны дорабатываться, тестироваться и отключаться независимо.

## Решение

Модули с интерфейсом `Module` (Init/Start/Stop), общение только через контракты (`internal/contracts`), реестр сервисов, реестры точек расширения и шину событий. Модули не импортируют друг друга. Встроенные модули перечислены явно в `internal/app/modules.go`.

## Последствия

Чуть больше шаблонного кода; взамен — изоляция и расширяемость. Границы проверяются автоматически (ADR-0016).

## Альтернативы

Монолит с прямыми импортами.
