# ADR-0008: Веб-GUI на Svelte 5, встроенный в бинарник

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC.md §3 (D8)

## Контекст

Нужен GUI с конструктором, без тяжёлого GUI-тулкита.

## Решение

Svelte 5 + TypeScript + Vite; сборка встраивается через `go:embed`; без собранного фронтенда отдаётся заглушка, чтобы `go build` работал без Node.

## Последствия

Интерфейс открывается в любом браузере; Node нужен только разработчикам фронтенда.

## Альтернативы

GTK/Qt (cgo), Electron/Tauri (вес и зависимости).
