# ADR-0015: Подробные комментарии на русском

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC.md §3 (D15)

## Контекст

Код должен читаться человеком, который видит его впервые (требование владельца).

## Решение

Doc-комментарий у каждого пакета (doc.go), типа и функции; комментарий «что делает этот блок» у каждого логического блока; для неочевидного — «почему». Комментарии пишутся на русском; идентификаторы, логи и коммиты — на английском.

## Последствия

Больше текста в коде; правила — в `docs/code-style.md` и `AGENTS.md` §6.

## Альтернативы

Английские комментарии (отклонено владельцем).
