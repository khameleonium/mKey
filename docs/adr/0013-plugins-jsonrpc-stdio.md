# ADR-0013: Плагины: Lua и процессы с JSON-RPC 2.0 через stdio

- **Статус:** принято
- **Дата:** 2026-09-30
- **Связано:** SPEC.md §3 (D13)

## Контекст

Сторонние авторы должны расширять mKey на любом языке, не роняя демон.

## Решение

Три вида плагинов: Lua, процесс (JSON-RPC 2.0, одно сообщение на строку через stdin/stdout), данные (YAML).

## Последствия

Изоляция сбоев, независимость от языка; нужен SDK и тестовый хост.

## Альтернативы

Go `plugin` (.so: точное совпадение тулчейна, cgo, нет выгрузки); hashicorp/go-plugin (gRPC, тяжелее для не-Go).
