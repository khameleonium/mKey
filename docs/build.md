# Самостоятельный файл макроса

Из любого проекта mKey можно собрать **один файл-программу**, которая работает сама по себе: её
можно скопировать на другой компьютер с Linux и запустить — устанавливать и настраивать mKey там не
нужно (ADR-0042).

## Как собрать

- **В окне:** откройте проект → «Собрать в файл» → выберите, что делать файлу, → «Собрать». Готовый
  файл можно скачать или найти в папке собранных макросов («Настройки» → «Где что лежит»).
- **В терминале:**

  ```bash
  mkey build Игра                         # файл в папке собранных макросов (~/.local/share/mkey/builds)
  mkey build Игра -o ~/Рабочий_стол/игра   # файл по пути
  mkey build Отчёт --once fill            # выполнить событие fill и завершиться
  ```

## Что делает файл

| Режим | Что происходит при запуске |
|---|---|
| «Работать, как проект» (по умолчанию) | горячие клавиши, таймеры, привязки и виртуальные устройства проекта работают, пока файл не закроют: значок mKey в трее → «Выйти», Ctrl+C в терминале или конец сеанса |
| «Выполнить и выйти» (`--once событие`) | выполняется одно событие проекта, и файл завершается — удобно для «нажал и готово» |

Внутрь кладутся проект (как есть, с комментариями) и записи и скрипты, на которые он ссылается
(`play`, `lua {file}`, `shell {file}` — в том числе внутри «Повторять» и «Если»). Действия
плагинов в файл не положить — сборка объяснит, какие убрать.

## Запуск на другом компьютере

1. Скопируйте файл и запустите его — двойным щелчком или в терминале (`./игра`).
2. Если на том компьютере ещё нет доступа к устройствам ввода, файл скажет об этом. Один раз
   выполните `./игра --setup-access` — спросит пароль администратора и даст доступ (так же, как
   установка mKey).
3. Экстренная остановка — **Esc + Backspace + Enter** — работает и в собранном файле.

Другие параметры: `./игра --info` — что внутри и чем собрано, `./игра --help` — справка.

Файл работает на компьютере с той же архитектурой процессора, что и у собравшего его mKey
(обычный компьютер — x86-64). Весит он столько же, сколько сама программа mKey (15–25 МБ).

## Важно

- Содержимое файла не зашифровано: `--info` и любой архиватор покажут проект.
- Запускайте только файлы, которым доверяете: внутри могут быть скрипты bash.
- Собранный файл не трогает установленный mKey: у него своя временная папка, которая удаляется
  при выходе.
